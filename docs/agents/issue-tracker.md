# Issue tracker

Issues for this repo are tracked in **GitHub Issues** in `haseeb-heaven/token-zero-studio`.

## Workflow

- Use the `gh` CLI to interact: `gh issue create`, `gh issue list`, `gh issue view <n>`, etc.
- Reference issues by number (e.g. `#123`).

## Request surface

PRs-as-a-request-surface: **off** (default). The triage queue tracks opened issues unless this flag is flipped.
