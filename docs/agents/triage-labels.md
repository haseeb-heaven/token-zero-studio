# Triage labels

Triage uses the canonical five-role vocabulary. Each label string equals its role name.

| Role | Label string |
|------|--------------|
| Needs triage | `needs-triage` |
| Needs info | `needs-info` |
| Ready for agent | `ready-for-agent` |
| Ready for human | `ready-for-human` |
| Wontfix | `wontfix` |
